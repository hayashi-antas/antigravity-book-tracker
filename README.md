
# Book Tracker (AIDD Training)

AIエージェント **AntiGravity (AG)** を活用した、AI駆動開発（AIDD）の習得と検証を目的としたプロジェクト。

## 🎨 User Experience (UX) Highlights
ユーザーが「直感的かつストレスなく」操作できるインターフェースを追求しました。

### 1. 質感と心地よさ（Motion & Feedback）
* **スタッガー・アニメーション (Framer Motion)**
    本のリストが表示される際、すべての要素が一度に出るのではなく、わずかな時間差（スタッガー）をもって下からふわっと浮き上がるように実装。情報の密度が高くても視覚的な圧迫感を与えない演出を行っています。
* **インスタント・トースト通知**
    データの追加・更新・削除の完了を `react-hot-toast` で即座に通知。画面遷移を待たずとも操作の結果が視覚的にフィードバックされるため、リズムを崩さずに管理作業を続けられます。

### 2. インテリジェントなデータ管理（Logic & Flow）
* **シームレスな進捗更新**
    詳細画面の「進捗スライダー」により、1%刻みの細かな読書状況の更新が可能。数値入力を簡略化し、変化を視覚的に楽しみながら管理できるUIを採用しました。
* **リアルタイム・フィルタリング**
    検索窓への入力と同時にリストが絞り込まれる高速な検索体験。Zustandの状態管理を活用し、待機時間（Loading）を感じさせない挙動を実現しています。
* **無限スクロールの採用**
    `Intersection Observer` を活用し、データ量が増えてもパフォーマンスを維持。ページ遷移の手間を省き、自然なスクロールで全ての蔵書にアクセスできます。

### 3. ストレスフリーな設計（Accessibility & Performance）
* **ハイドレーションの完全制御**
    LocalStorageからのデータ復旧時に発生しがちな「表示のちらつき（Hydration Mismatch）」を、Zustandの独自ロジックで制御。初期読み込みから安定した表示を提供します。
* **適応型ダークモード**
    `next-themes` によりシステム設定に即座に反応。夜間の読書記録でも目に優しいデザインを自動的に提供します。
* **堅牢なバリデーション**
    `Zod` と `React Hook Form` の連携により、不完全なデータ入力を送信前にブロック。ユーザーがエラー箇所を即座に理解できるインラインメッセージを表示します。

### 4. データの物語化（Visual Statistics）
* **直感的なダッシュボード**
    `Recharts` を用いた統計グラフは、単なる数字の羅列を「自分の成長の記録」に変えます。ジャンル比率や進捗率が視覚化されることで、次の1冊へのモチベーションを高める設計としました。
## 🎯 研修の目的

* **AI駆動開発の実践**: AIエージェントとの対話による設計・実装・テストの自動化。
* **最新技術の習得**: Next.js 16 / Tailwind CSS 4 等の最新スタックの迅速な実装。
* **環境構築スキルの向上**: Docker (Dev Containers) 環境下でのトラブルシューティング。

## 🛠 技術スタック

* **Framework**: Next.js 16 (App Router)
* **Styling**: Tailwind CSS 4 / Framer Motion
* **State**: Zustand (Persistence)
* **Testing**: Vitest
* **Environment**: Docker / AntiGravity (AI Agent)

## 🚀 AIDDプロセスの要点

1. **自律実装**: 自然言語の指示から、AGによるディレクトリ構造の構築、コンポーネント実装、依存関係の解決までを自動化。
2. **型安全と検証**: AGによる TypeScript 型エラーの自己修復、および `npm run build` によるビルドチェックの完遂。
3. **効率的なデバッグ**: Docker環境特有の権限問題（Permission Denied）等を、AIとの対話によって論理的に解消。

## 📝 主な実装機能

* **Dashboard**: Rechartsを用いた読書データの統計可視化。
* **Book Management**: 無限スクロール、リアルタイム検索、CRUD操作。
* **Persistence**: LocalStorage を利用したデータの永続化。
* **Validation**: Zod を用いた厳格なフォームバリデーション。
